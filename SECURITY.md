# Segurança

Se encontrares uma vulnerabilidade ou dados pessoais expostos neste repositório ou no site, não abras uma issue pública. Usa a funcionalidade [Report a vulnerability](https://github.com/tpereira2005/intercalares-eua-2026/security/advisories/new) do GitHub.

O projeto não guarda dados pessoais de visitantes nem publica dados individuais de eleitores.
